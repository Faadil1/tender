# Demo Script

## 0-10 seconds

Accepted software work and payment usually live in separate systems.

## 10-25 seconds

Show the accepted contribution and the policy that defines what is due.

Line: GitHub proves what work was accepted.

## 25-45 seconds

Tender creates one Tender Claim from that accepted work: repository, task, accepted-work identity, policy version, recipient, asset, and amount.

Line: Tender proves what is owed.

## 45-70 seconds

KeeperHub settles the claim on Base Sepolia. Tender records the execution ID, transaction hash, and Tender Receipt.

Line: KeeperHub proves it was paid.

## 70-90 seconds

Replay the exact same accepted contribution.

Expected screen:

`REPLAY -> SAME CLAIM -> $0 MOVED`

Line: One accepted obligation, one settlement.

## Closing

No bounty. No race. Accepted work becomes a claim.
